# Lucci Labs

Studying intelligent systems by building them.

Lucci Labs is the research and development arm of [Lucci](https://luccihq.com).

- [Lucci Labs](https://luccilabs.xyz) — research, experiments and public project information.
- [Writing](https://luccilabs.xyz/writing) — published research notes and reports.
- [Building](https://luccilabs.xyz/building) — public software projects.
- [Loop numerical supplement](https://huggingface.co/datasets/luccilabs/loop-measurement-supplement) — derived tables and analysis scripts for the published wrist-sensing pilot. Raw recordings and the full capture application are not public.
